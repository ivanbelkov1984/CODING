Наряд студии Белькова #189. Разобрано вручную по `pubspec.lock` (151 пакет) —
не по заголовкам, по фактическим лицензиям пакетов.

## Copyleft (GPL/LGPL/AGPL)

**Не найдено ни одного.** Подавляющее большинство пакетов — стандартная
экосистема Dart/Flutter: команда Dart/Google публикует свои пакеты под
BSD-3-Clause (`http`, `path`, `intl`, `collection`, `async`, `meta`,
`mockito`, `oauth2` и т.д.), сообщество — под MIT или Apache-2.0
(`dio`, `provider`, `logger`, `flutter_secure_storage`, `hive`, `sentry`,
`pdf`, `uuid`, `flutter_svg`, `sqflite`, `shared_preferences`, `fl_chart`
и их платформенные плагины). Ни один из этих типов лицензий не обязывает
открывать исходный код закрытого продукта.

## Флаг — не copyleft, но требует решения Ивана Ивановича

**`syncfusion_flutter_charts` / `syncfusion_flutter_core`** — это НЕ открытый
код с permissive-лицензией, а коммерческий продукт Syncfusion Inc. под их
собственным EULA. Использование легально при одном из двух условий:
1. Куплена коммерческая лицензия Syncfusion, ИЛИ
2. Проект подпадает под их бесплатную **Community License** (годовой доход
   компании < $1M USD И ≤ 5 разработчиков, использующих продукты Syncfusion).

**Решение нужно от Ивана Ивановича:** подпадает ли студия/проект под условия
Community License, или нужно покупать лицензию. Без этого — риск нарушения
условий использования коммерческого ПО (не copyleft, но реальный юридический
риск другого рода).

## GDPR / персональные данные

Проверил `storage_service.dart` и `auth_service.dart`:
- Учётные данные (`clientId`, `apiKey`) и профили пользователя хранятся через
  `FlutterSecureStorage` — зашифрованное платформенное хранилище (Keychain на
  iOS, Keystore на Android), НЕ открытым текстом. Соответствует требованию
  безопасного хранения.
- Побочная находка (вне рамок этого наряда, для Никиты — наряд #191):
  `auth_service.dart` логирует полное тело ответа API при успешной
  авторизации (`logger.i('Authentication successful: $data')`) — тело ответа
  API продаж потенциально содержит коммерческие данные продавца. Не секрет
  авторизации напрямую, но избыточное логирование стоит сузить.

## Вывод

Copyleft-риска нет. Единственный открытый вопрос — коммерческая лицензия
Syncfusion, решение по нему за директором.
