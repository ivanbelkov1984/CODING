# Claude Code — проект «Архитектор жизни»

## Источник правды

Репозиторий: `ivanbelkov1984/CODING`. Каноническая ветка: `MAIN`. Приложение находится в `architect/`.

Перед любой работой:

1. прочитай `STUDIO_HANDOFF.md` и последние записи журнала;
2. выполни `git fetch origin`, `git log --oneline -20`, изучи незнакомые diff;
3. прочитай `architect/AGENT_BRIEF.md`;
4. для астрологической задачи начни с `architect/docs/astrology/00-IMPLEMENTATION_INDEX.md`;
5. активируй текущую сложную сессию командой `/effort ultracode` и проверь `/status`;
6. не начинай код до Phase 0 repository audit и утверждённого task contract.

## Неподвижные ограничения

- Дополняй существующий vanilla-JS/offline-first PWA; не переписывай приложение на React, TypeScript или новый фреймворк без отдельного ADR владельца.
- Не помещай реальные дневники, психологические материалы, даты жизненных событий и другие личные данные в git, issue, PR, логи или тестовые fixtures.
- LLM не рассчитывает астрологию и не изменяет raw calculation facts.
- Астрология не создаёт медицинские, психологические, юридические или финансовые решения.
- Ректификация создаёт `RectificationHypothesis`, а не перезаписывает `OriginalBirthEvidence`.
- Модуль сценарного прогнозирования не выдаёт вероятность будущего события из астрологии или произвольных коэффициентов. Вероятности разрешены только для заранее определённого outcome после независимой temporal/external validation и calibration.
- Любой fallback, uncertainty и degraded mode показываются явно.
- Никогда не проси Ивана вручную написать код. Проси только продуктовые, юридические, лицензионные или необратимые решения, которые агент не вправе принимать сам.

## Harness

Следуй `.claude/harness-rules.md`. Держи основной контекст компактным: контракт, решения, зависимости и acceptance criteria. Исследования, большие логи и изолированные реализации отдавай специализированным агентам/динамическим workflow.

14 ролей зарегистрированы, но одновременно активируй обычно 3–5. Не запускай все 14 ради масштаба. Один файл не должен параллельно редактироваться несколькими агентами.

## Проверка

Для изменения приложения:

```bash
cd architect
node --check app.js
node build.mjs --combined dist/app.html
npm test
```

UI-поведение дополнительно проверяется в мобильном viewport и по актуальному `architect/design_guide.md`, `architect/PATTERN_LIBRARY.md`, `design/tokens.json`.

После завершённого куска: понятный commit, push по действующему протоколу, запись в `STUDIO_HANDOFF.md`.
