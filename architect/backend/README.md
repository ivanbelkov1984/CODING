# Архитектор — Backend

Сервер синхронизации для приложения «Архитектор». Хранит данные пользователя
в PostgreSQL и отдаёт их по секретному ключу-пространству (space key).
Это даёт кросс-девайс доступ: ввёл один ключ на телефоне и компьютере — видишь
одни и те же данные.

## Технологии
- **Express** — HTTP API
- **PostgreSQL** — хранилище (одна таблица `spaces`, данные в JSONB)
- **Railway** — хостинг

## API

| Метод  | Путь               | Назначение                          |
|--------|--------------------|-------------------------------------|
| GET    | `/health`          | проверка живости + БД               |
| POST   | `/api/space`       | создать пространство → `{ key }`    |
| GET    | `/api/space/:key`  | загрузить данные (pull)             |
| PUT    | `/api/space/:key`  | сохранить данные (push)             |
| DELETE | `/api/space/:key`  | удалить пространство                |

Тело для `POST`/`PUT`: `{ "db": {...}, "cfg": {...}, "name": "..." }`

## Деплой на Railway (через веб, без CLI)

1. Зайди на **railway.app** → **New Project** → **Deploy from GitHub repo**
2. Выбери репозиторий `ivanbelkov1984/CODING`
3. В настройках сервиса задай **Root Directory**: `architect/backend`
4. Нажми **+ New** → **Database** → **Add PostgreSQL**
   (Railway сам пропишет переменную `DATABASE_URL`)
5. Дождись деплоя. Открой вкладку **Settings → Networking → Generate Domain** —
   получишь публичный URL вида `https://architect-backend-production.up.railway.app`
6. Скопируй этот URL и вставь в приложении:
   **Карта → Настройки → Конфигурация осей → URL Backend**

После этого кнопка **Синхронизировать** в приложении:
- при первом нажатии создаёт пространство и сохраняет ключ локально,
- при следующих — пушит изменения на сервер.

На другом устройстве: введи тот же **URL Backend** и тот же **Ключ пространства**
(скопируй его из Конфигурации первого устройства) → нажми **Загрузить с сервера**.

## Локальный запуск

```bash
cd architect/backend
cp .env.example .env      # пропиши свой DATABASE_URL
npm install
npm start
```

Сервер поднимется на `http://localhost:3000`, схема создастся автоматически.
