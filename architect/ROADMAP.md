# Архитектор — дорожная карта развития

Синтез внутреннего аудита кода + исследования рынка (2025–2026).
Цель: превратить «хранилище ввода» в **зеркало, которое отвечает** — замкнуть
петлю ввод→смысл, добить настоящий офлайн-PWA, усилить безопасность.

## Принятые технические решения (с обоснованием)

| Область | Решение | Почему |
|---|---|---|
| Графики | Ручной SVG (в стиле радара), опция uPlot для тяжёлых серий | Zero-dep, офлайн, консистентно с кодовой базой |
| Статистика | 7-дневное скользящее среднее; честные пропуски (без интерполяции); корреляции только при n≥20–30 с показом n и метки «нужно больше данных» | Малые личные датасеты статистически шумны; честность = дифференциатор доверия |
| Даты | ISO 8601 UTC (`createdAt`) + отдельная локальная дата-метка `day`; `schema_version` в записях | Чинит сортировку/фильтры/напоминания; устойчиво к смене часовых поясов |
| Синхронизация | Per-record LWW (уже есть) + field-level merge для скаляров/глав | CRDT избыточен для одиночного пользователя; средний путь |
| Шифрование | Оставить AES-GCM, поднять PBKDF2 до ~210k; recovery-код (обёртка мастер-ключа); Argon2id/passkey — позже | WebCrypto без Argon2; прагматичный баланс |
| Бэкенд | helmet, express-rate-limit, лимит тела 1–2MB, CORS allowlist, опц. пароль пространства, валидация JSONB, бэкапы | Модель «ключ=всё» требует второго фактора и защиты от абьюза |
| PWA | Workbox SW (app-shell), manifest.json, самохостинг шрифтов/иконок | Реальный офлайн и установка; без CDN-зависимости |
| Уведомления | Web Push (iOS 16.4+ установленный PWA) + Notification API fallback | Надёжные напоминания о чек-ине |
| AI | Opt-in; расшифровка в памяти клиента → вызов Claude API напрямую с клиента (плейнтекст не проходит через наш сервер) | Приватность + качество сводок |
| Связи | Парсинг `[[wiki-links]]`, обратный индекс, мини-граф (d3-force/force-graph) | Оживить «Карту»; редкость в mood-трекерах |
| Доступность | WCAG 2.2: контраст 4.5:1, focus-trap в шторках, Escape, тач-таргеты 44px | База доступности к 2026 |

## Фазы

### P0 — замкнуть петлю и починить фундамент ✅ ГОТОВО
- [x] Даты → ISO (`createdAt`+`day`+`schema_version`), миграция старых записей, починка сортировки и `smartTriggers`
- [x] Экран трендов: чек-ины (ясность/стресс/мотивация/сон) за 30 дней, 7-дн. скользящее среднее, показ n, честные пропуски
- [x] Реальный дайджест недели из фактических данных (топ-инсайты, динамика состояния, паттерны, счётчики)
- [x] Undo для удаления (тост «Отменить» ~6с, восстановление + снятие надгробия)

### P1 — связность и удержание (в работе)
- [x] Настоящие связи `[[...]]` + бэклинки (стем-матч по падежам) → «Карта» оживает *(мини-граф — позже)*
- [ ] Радар, производный от логов (скользящее состояние → оси) с ручной коррекцией
- [ ] Service worker (Workbox) + manifest + самохостинг Inter/lucide → устанавливаемый офлайн-PWA
- [ ] Напоминание о чек-ине (Notification API + Web Push для установленного PWA)
- [x] Разделение текущего/лучшего стрика *(«на этот день» — позже)*
- [x] Управляемая рефлексия из «открытых вопросов» (тап по вопросу → инсайт)

### P2 — зрелость и безопасность
- [x] Бэкенд: helmet + rate-limit + CORS allowlist + лимит тела + валидация JSONB *(бэкапы — позже)*
- [ ] Пароль пространства (2-й фактор, хэш на сервере) + recovery-код шифрования
- [ ] Field-level merge для глав/скаляров; предупреждение о невосстановимости при потере фразы
- [ ] Argon2id (WASM) как апгрейд KDF; passkey/WebAuthn как обёртка ключа
- [ ] Рефакторинг в модули + типы (JSDoc/TS) + тесты в репозитории + CI
- [ ] Экспорт в Markdown/PDF

### P3 — «на 10 шагов вперёд»
- [ ] Агентный лайф-коучинг (проактивные вопросы/инсайты из данных)
- [ ] Честные корреляции факторов (сон↔состояние) с доверительными метками
- [x] Opt-in AI: AI-обзор недели + AI-вопросы рефлексии (Claude API напрямую с клиента, ключ локально)
- [ ] Интеграция с носимыми/Health (импорт сна/пульса)
- [ ] Годовой ретро + сезонные обзоры
