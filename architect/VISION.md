# Архитектор — живое видение продукта

> Этот файл — единый источник правды о том, чем является «Архитектор» прямо
> сейчас. Он отвечает на вопрос «что это и зачем», а не «что нам предстоит».
> Обновляется вместе с кодом: если что-то реализовано — сюда тоже вносится.

---

## Суть в одной фразе

**Архитектор** — личный дневник жизни, который держит в уме все твои сферы,
правильно структурирует память на годы и превращает данные в действенные
выводы. Не трекер ради красивых графиков: **данные → смысл → конкретное
действие**.

---

## Чем приложение отличается от аналогов

| Что другие делают | Что делаем мы |
|---|---|
| Красивые графики без вывода | Формулируем «что тебе помогает» — с лагом, уверенностью и конкретным шагом |
| Жёсткий стрик — сбросил, начинай с нуля | «Прощающая» метрика постоянства — плавное затухание, не обнуление |
| AI по кнопке «проанализируй» | Интеллект вплетён: связи находятся сами, амбиентно всплывают в нужном месте |
| Фиксированные 8 осей жизни | Любые сферы с 5 типами трекера (балл / привычка / счётчик / цель / лог) |
| Данные за один сезон | Память на годы: «похожее состояние было год назад — вот что тогда помогло» |
| Психологический разбор по кнопке | Метод «Зачем?» как постоянный слой: симптом → функция → вторичная выгода → потребность |
| Не делает никто | **Единый смысл через все сферы сразу** — корреляции между любыми сферами, общий вывод |

## Архитектура продукта (три слоя)

### Слой 1 — Ввод (низкое трение)
- **Чек-ин дня**: сон, ясность, стресс, движение, RULER-эмоция, 4 фактора
  (никотин/кофеин/алкоголь/сладкое), заметка — всё в одном экране.
- **Сферы жизни** (пользовательские): балл / привычка / счётчик / цель /
  лог-дневник. Каждая сфера сама выбирает тип → правильный визуал автоматически.
- **Инсайты** с `[[wiki-связями]]`, сны, духовное, паттерны — свободный
  текст, ИИ размечает психологически в фоне.
- **Тяга** (здоровье): лог импульса — вид, триггер, сила 0–10; при силе ≥6
  инлайн-интервенция (дыхание/вода/движение) прямо в моменте.

### Слой 2 — Умный движок (соль приложения)
Пересчитывается при каждом изменении данных. Семь способностей:

1. **Действенные выводы** — «когда спишь >7ч, состояние выше на 20%», с
   конкретным действием и честной меткой уверенности по n.
2. **Паттерны со сдвигом** — лаг 0/+1/+7 дней: «плохой сон → провал завтра»,
   «спорт → лучше через день».
3. **Память на годы** — ресёрфейсинг: «похожее было год назад — вот инсайт,
   который тогда помог» (interval spaced resurfacing).
4. **Кросс-сферовые корреляции** — «в дни спорта ясность на 1.4 балла выше»;
   единый смысл через все сферы.
5. **Персональный риск-движок** (здоровье) — `cravingRisk`: учится на твоей
   истории срывов (окно суток, пост-срыв AVE 48ч, одиночество), объясняет
   причины, предупреждает до тяги.
6. **Психологический контур** (метод «Зачем?») — ИИ размечает каждую запись:
   симптом/функция/вторичная выгода/потребность/состояние Я/эмоция/игра/
   смысловые темы. Связи — через психологические сущности, не по словам.
7. **Живая сеть связей** — кросс-доменные рёбра: тема↔тема, запись↔сфера,
   сфера↔состояние, со-встречаемость по дню. Амбиентно всплывают в нужном месте.

### Слой 3 — AI (Claude, опционально, по ключу пользователя)
- **Маршрутизация по классу**: лёгкие задачи (отклик/вопрос) → дешёвая модель;
  глубокий анализ (обзор недели/карта жизни) → мощная модель.
- **Леджер расходов**: каждый вызов записывается с токенами и стоимостью;
  экран «Расходы AI» с разбивкой по задачам и моделям.
- **Бюджет**: мягкий месячный порог — предупреждение при 80%, остановка при 100%.
- **Точки AI**: отклик наставника на запись, «Копни глубже» (диалог-цепочка),
  автономный обзор недели, психологический контур, сонник, Therapeutic Generator
  (грounded: выбирает метод строго из нашего каталога, не придумывает).
- **Кризисный протокол**: три слоя безопасности — локальный регекс + флаг ИИ +
  проверка ответа; при срабатывании — карточка без диагнозов, ведёт к живому
  человеку.

## Структура приложения (4 вкладки)

| Вкладка | Что тут | Зачем |
|---|---|---|
| **Сегодня** | Состояние-герой (радар+балл+contributors), чек-ин, тепловая карта 90 дней, «что помогает», тизер графа, стрик, «год назад», открытые вопросы | Точка ежедневного входа |
| **Сферы** | Карточки сфер (5 типов трекера), радар, тренд, цели, привычки, корреляции | Твоя жизнь по всем фронтам сразу |
| **Разум** | Инсайты (фильтр/граф/бэклинки), смысловая карта тем, психоконтур, книга/главы, сны, паттерны, эволюция | Знания и связи накапливаются |
| **Итоги** | Живая карта жизни (AI-нарратив), дайджесты/недели/месяц/год, ретроспектива, AI-обзор | Замыкает петлю «данные → смысл» |
| **Здоровье** | Риск сейчас, лог тяги, паттерны срывов, «что влияет», приёмы саморегуляции, психическое состояние, Среда, план «если→то» | Зависимости как часть ДНК, не отдельная фича |
| **Настройки** | Профили, синк, шифрование, AI-ключи, расходы AI, бюджет, экспорт | Инфраструктура под контролем |

## Инфраструктура (что внутри, что незаметно)

- **Offline-first PWA**: ставится на домашний экран, работает без сети, app-shell SW.
- **E2E-шифрование (AES-GCM v2 envelope)**: фраза локальна, DEK заворачивается
  фразой + ключом восстановления; сервер видит только шифроблоки, разработчик не читает память.
- **LWW-синхронизация** по записям с тумбстонами: несколько устройств,
  без конфликтов.
- **Мультипрофиль**: данные неймспейсятся по id профиля.
- **Снапшоты**: ежедневно 7 точек восстановления в localStorage.
- **Backend (Railway)**: хранит только зашифрованные блоки; helmet, rate-limit,
  CORS allowlist, Web Push (VAPID, готов к активации).
- **AI-приватность**: ИИ-слой работает напрямую браузер→провайдер по ключу
  пользователя; дневниковое содержимое никогда не проходит через сервер
  приложения.

## Дизайн-система (Linear-подход)

Глубина — поверхностями, а не тенями. Монохромная лестница (bg1→bg4),
hairline-границы, нулевые тени, один акцентный цвет. Inter, семь ступеней
типографики. Светлая и тёмная темы. Реализуется чистым CSS — без библиотек
и без сборщика.

---

## Честность как дифференциатор

- Уверенность по n: «мало данных» / «наблюдение» / «устойчивая связь».
- Пустое состояние говорит СКОЛЬКО не хватает: «ещё 3 чек-ина — и покажу связь».
- Кризис-протокол честно: «Архитектор — не терапевт».
- Undo на удаление (6 сек) — потерять данные случайно невозможно.
- AI-ключ только у пользователя; провайдер видит текст запроса, мы — нет,
  экран «Конфиденциальность» объясняет это прямо.

---

## Что НЕ является целью

- Не дашборд аналитики для команды.
- Не корпоративный life-OS с онбордингом.
- Не health-app с серверным ML на когорте пользователей.
- Не трекер ради красивой статистики.

Один человек, один профиль (или несколько — на одном устройстве), данные
только у него — и зеркало, которое отвечает.
