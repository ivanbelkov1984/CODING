# Архитектор — разбор функционала, конкуренты, чего не хватает

> Цель владельца: **ежедневник жизни по всем фронтам**, где пользователь
> создаёт **свои универсальные сферы жизни** (духовные практики, книга, хобби,
> дела…), и каждая сфера отслеживается своим инструментом. Это документ-основа
> для решения о структуре меню — дизайн собираем ПОСЛЕ утверждения модели.

## 1. Что уже есть в приложении (полная карта)

### Данные (коллекции)
- **insights** — инсайты/заметки: тег, вес, источник, `[[связи]]`.
- **dreams** — сны (с тоном).
- **patterns** — паттерны (+ автодетект из инсайтов).
- **evolution** — журнал эволюции (уровни).
- **spiritual** — духовные практики.
- **checkins** — ежедневный чек-ин: сон (часы+качество), ясность, стресс,
  движение, никотин/кофеин/алкоголь, активность, тон, заметка.
- **bots** — задачи (приоритет, done).
- **chapters** — главы «книги»/домена (статус, флаги).
- **digests** — недельные обзоры (+ AI).
- **oq** — открытые вопросы для рефлексии.

### Конфиг
- **axes** — 8 ФИКСИРОВАННЫХ осей жизни (Здоровье/Деньги/Работа/Творчество/
  Окружение/Психология/Духовное/Домен), у каждой метка, балл 0–10, цвет.
- domainLabel, weekFocuses, AI-модель, sync (URL/ключ/шифрование).

### Функции/экраны
- **Главная** (обновлена): состояние-герой `stateScore` (композит+база+contributors),
  тепловая карта 90 дней, корреляции, граф-тизер, стрик, «год назад», открытые
  вопросы, последние инсайты, быстрые действия.
- **Инсайты**: фильтр по тегам, сортировка, детали+бэклинки, правка, undo-удаление, share.
- **Книга/Домен**: главы с кольцами прогресса.
- **Жизнь**: чек-ин, тренд 30 дней, 8 осей-баров, «по чек-инам».
- **Система**: дайджест + AI-обзор, синхронизация.
- **Карта**: бот-задачи, паттерны, сны, духовное, граф связей, эволюция, настройки.
- **Команды**: /актуально /книга /паттерны /карта /состояние /дайджест /ретро.
- **AI (Claude)**: обзор недели, вопросы рефлексии.
- **Инфраструктура**: мультипрофиль, offline-first sync, версии+merge, E2E-шифрование, PWA.

**Сильные стороны:** данные+синхронизация+шифрование, граф связей, композит
состояния, корреляции, AI, профили. Это уже больше, чем у типового мудтрекера.

## 2. Конкуренты — какие механики стоят за ними

| Приложение | Ключевая механика (не вид, а функция) |
|---|---|
| **Exist.io** | Любой **кастомный тег/атрибут** трактуется как данные и **коррелируется со всем остальным** (сон, настроение, погода, продуктивность). «Что помогает/мешает». |
| **Daylio** | Быстрый лог (2 тапа) + **кастомные активности** + **цели** (день/неделя/месяц) + **привычки со стриками** + корреляции + год-в-пикселях. |
| **Notion life OS** | Полностью кастомные базы под любую сферу + связи. Гибко, но неумно и вручную. |
| **Oura/Whoop** | Композитный балл (readiness/recovery) относительно личной базы, тап → contributors. |
| **Obsidian/Logseq** | Двусторонние ссылки + граф + **ежедневные заметки** (daily notes). |
| **Habitica/Streaks** | Привычки с расписанием и стриками, геймификация. |
| **Reflectly/Stoic** | Управляемые ритуалы утро/вечер, ротация промптов, обзоры недели/года. |
| **Gyroscope/Rise** | Дашборд из нескольких «областей жизни» с трендами. |

## 3. Чего нам не хватает (gaps) — по приоритету

**P0 — ядро под твою идею:**
- **A. Пользовательские универсальные сферы.** Сейчас оси ЖЁСТКО заданы (8 штук).
  Нужно: пользователь создаёт любую сферу (Спорт, Отношения, Книга, Медитация…)
  с именем, цветом, иконкой И **своим типом трекера** (см. §4).
- **B. Привычки со стриком на каждую сферу.** Сейчас стрик один — на чек-ин.
- **C. Цели/таргеты на сферу.** «12 книг», «медитация 20 мин/день», прогресс к цели.

**P1 — ежедневник по всем фронтам:**
- **D. Экран «Сегодня» — единый лог дня по всем сферам** (чек-ин + привычки +
  быстрые записи + намерения дня), а не только vitality-чек-ин.
- **E. Корреляции по ЛЮБОЙ сфере** (механика Exist): «в дни спорта состояние выше».
- **F. Управляемые ритуалы/промпты** утро/вечер (ротация, могут быть AI-генерируемые).
- **G. Календарь/таймлайн** всех записей по месяцам (сейчас тепловая карта только по настроению).

**P2 — глубина:**
- **H. Напоминания/уведомления** (Web Push — нужна инфраструктура).
- **I. Медиа в записях** (фото, голос).
- **J. Обзоры месяц/год** (сейчас неделя + «год назад»).
- **K. Экспорт Markdown/PDF.**

## 4. Ключевая идея: универсальная сфера с типом трекера

Заменяем фиксированные 8 осей на **список сфер**, где у каждой — свой инструмент:

| Тип трекера | Для чего | Что рисуем |
|---|---|---|
| **Балл 0–10** | самочувствие, удовлетворённость (Здоровье, Отношения) | ось радара + тренд |
| **Привычка (да/нет)** | медитация, зарядка, без сахара | стрик + тепловая карта |
| **Счётчик (число)** | страниц прочитано, км пробежки, минут практики | сумма/среднее + спарклайн |
| **Значение с целью** | вес, накопления, «12 книг за год» | прогресс к цели (кольцо) |
| **Лог-заметки** | дневник сферы, духовные записи | лента записей + граф `[[связей]]` |

Каждая сфера сама выбирает тип → и Главная/Итоги показывают её правильным
визуалом. Корреляции работают между любыми сферами. Это объединяет Exist
(кастом+корреляции), Daylio (привычки/цели), Oura (композит), Obsidian (связи)
в одну систему — и точно ложится на «свои сферы по всем фронтам».

## 5. Структура меню, вытекающая из функционала

Меню следует за жизненным циклом данных: **залогировал → увидел состояние →
связал мысли → подвёл итоги.**

1. **Сегодня** — единый лог дня по всем сферам (чек-ин, привычки, счётчики,
   намерения, быстрая запись). Точка ежедневного входа.
2. **Сферы** — твои сферы жизни, каждая своим трекером + тренд + цель +
   композитный радар сверху. (Новое ядро, заменяет «Жизнь».)
3. **Разум** — инсайты + граф-карта + книга/главы + сны (знаниевая сторона).
4. **Итоги** — дайджест/обзоры + корреляции + ретроспектива + AI.

4 вкладки вместо 6, без дублей: оси/сферы — только в «Сферы», инсайты — только
в «Разум», состояние — на «Сегодня»/«Сферы».

## 6. Что решить перед дизайном
1. Утвердить **модель сфер + 5 типов трекера** (§4) — это фундамент.
2. Утвердить **4 вкладки** (§5) или скорректировать.
3. Выбрать, что берём в первую волну: сферы+привычки+цели (P0) → потом «Сегодня» и расширенные корреляции.
