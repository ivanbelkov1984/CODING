# Психологический контур — интеграция метода «Зачем?»

Основа: научно-методический труд владельца «Метод „Зачем?" как инструмент
выхода из психологической зависимости» (интеграция логотерапии В. Франкла,
транзактного анализа Э. Бёрна, теории привязанности Дж. Боулби,
эмоциональной регуляции Д. Гоулмана).

## Принцип
Связи между записями создаются НЕ механически (по повторяемым словам),
а осознанно — ИИ размечает каждую запись по схеме метода, и система
связывает записи по психологическим сущностям.

## Схема разметки записи (i.psy)
| Поле | Источник в методе |
|---|---|
| symptom | шаг 1 — фиксация симптома словами автора |
| func | шаг 3 — функция симптома (Франкл: «зачем», не «почему») |
| gain | шаг 4 — вторичная выгода (Бёрн: payoff) |
| need | глубинная потребность (фикс. таксономия: безопасность, принятие, значимость, автономия, смысл, близость, контроль, покой, новизна) |
| ego | состояние Я (Бёрн: Ребёнок/Родитель/Взрослый) |
| emotion | ядровая эмоция (Гоулман) |
| game | психологическая игра, если видна (Бёрн) |
| conf | уверенность разметки 0–100 |
| themes | 1–3 смысловые темы записи («о чём по сути») — питают смысловую карту |

## Где живёт в приложении
1. **Фоновая разметка** — `psyAutoRun()`: ИИ (лёгкая модель, задача «psy»)
   размечает неразмеченные записи батчами ≤5, при старте и каждые 10 мин.
   Правило: «не выдумывай — если не видно, ставь null».
2. **Вью «Психика»** (Разум → Карта → Психика): глубинные потребности
   с частотами (тап — записи), баланс состояний Я, повторяющиеся игры,
   цепочки «симптом → функция → выгода».
3. **Детали записи**: блок «Разбор по методу „Зачем?"» + осознанные
   связи «та же потребность».
4. **Диалог вглубь**: наставник ведёт строго по алгоритму метода —
   симптом → серия «Зачем?» (по одной за ход, 3–5) → функция →
   вторичная выгода → цена → альтернативный способ закрыть потребность →
   закрепление выбора.
5. **Заключение диалога**: сильная модель сжимает диалог в вывод и сразу
   размечает его по схеме — вывод входит в систему уже структурированным.
6. **Смысловая карта** (Разум → Карта → Темы): при наличии разметки ИИ
   узлы карты — не повторяемые слова, а смысловые темы (i.psy.themes);
   связи — темы одной записи и темы одной глубинной потребности.
7. **Сонник** (отдельный режим диалога для снов): не метод «Зачем?», а
   синтез толкования — Юнг (компенсация, Тень, амплификация), гештальт
   (элементы сна — части сновидца), научный слой (гипотеза непрерывности
   Холла/Домхоффа, репетиция угроз, консолидация памяти) — с опорой на
   жизненный контекст из дневника: свежие записи, потребности, состояние,
   паттерны. Заключение размечается по схеме метода, src «Разбор сна».

## Приватность
Разметка выполняется ключом пользователя, напрямую браузер → провайдер.
Психологические данные никогда не проходят через сервер приложения.
