# Design Guide — «Архитектор» × эстетика Linear

> Редизайн оболочки (не функционала) по канону: тихий минимализм, монохромная
> база, ОДИН акцент #5e6ad2, глубина слоями поверхностей, hairlines вместо теней.
> Калибровка по Linear: linear.app/now/how-we-redesigned-the-linear-ui и
> публичные разборы токенов (designmd.co/d/linear.app).

## Аудит (что нарушало систему — было)
- 23 box-shadow в хроме (карточки, таббар, тосты, сплэш).
- 8 декоративных градиентов (герой, sync-CTA, надж, ambient, глянец тепловой карты).
- 5 разных easing, включая пружинный cubic-bezier(.2,.9,.3,1.3).
- Радиусы вразнобой: 2/4/5/6/7/10/12/14/16/17/18/20/22px.
- Веса 600×55, 700×67, 800×11 — «жирная» иерархия.
- Две темы (light-канон + dark), декоративные hues в хроме: purple/teal/
  orange/gold/rose + 6-цветные теги, цветные плитки действий, цветные
  подписи осей радара, зелёное кольцо постоянства.

## Применено (стало)
- **Токен-слой**: старые имена переменных (--bg/--sf/--bd/--t1…/--blue/…)
  переназначены на Linear-палитру → весь var()-код подхватил систему без
  правки логики. Лестница: #08090a → #0f1011 → #141516 → #18191a → #191a1b.
  Hairlines #23252a/#34343a/#3e3e44. Текст #f7f8f8/#d0d6e0/#8a8f98/#62666d.
- **Один акцент** #5e6ad2 (+#7170ff/#828fff hover). Бывшие hues мигрированы:
  purple/teal → оттенки акцента; gold/rose → ступени индиго-рампы (интенсивность).
- **Тени = none** (все 23), глубина только поверхностями. Градиенты
  декоративные погашены (conic-кольца прогресса оставлены — функциональные).
- **Движение**: единый cubic-bezier(.2,0,0,1); 80/120/150ms; оверлеи
  scale .98→1 + fade 100ms; пружины удалены.
- **Типографика**: шкала 12/13/15/18/24/32; веса в полосе 400–510
  (800/700→510, 600→500); хедлайны letter-spacing −0.02em; иерархия
  размером/весом, не цветом (акцентные слова в заголовках → уровень текста).
- **Форма**: радиусы нормализованы к 4 (чипы/бейджи) / 8 (карточки, инпуты,
  кнопки) / 12 (модалки, крупные панели).
- **Компоненты**: кнопка-CTA — плоский акцент, 36px, r8; инпуты — surface-2 +
  hairline, фокус акцентом; чипы/теги — 4px, монохром с тихим тоном; список
  сфер — строки с разделителями (без карточных рамок), левая 2px полоса-
  идентификатор; таббар тихий (активная — surface-2 + акцентный текст);
  тосты — surface-4 + hairline (цвет только у границы/иконки функционально);
  оверлеи — surface-4, r12.
- **Дата-виз дисциплинирована** (цвет = функция): тепловая карта — индиго-рампа
  интенсивности, верхний тир — функциональный зелёный; радар — серые подписи
  осей + акцентные точки/полигон (через CSS поверх SVG-атрибутов, JS не тронут);
  кольца прогресса — акцент; зелёный/янтарь остались ТОЛЬКО функционально
  (рост «↑», «устойчивая связь», лучший/трудный день, предупреждения).
- **Единственная тема**: dark — канон (data-theme="dark", theme-color #08090a);
  обе ветки токенов указывают на одну палитру → переключатель визуально
  инертен и скрыт из настроек CSS-ом (JS не менялся).

## Проверка
- `npm test` — 26/26 зелёные после каждой волны правок (id/классы/поведение
  не менялись; JS не тронут вообще — редизайн только CSS + 4 строки <head>).
- Скриншоты (390px, dark): Сегодня (герой), Сферы, Разум, Итоги, оверлей
  «Новый инсайт» — визуально согласованы одной системой.

## На решение владельцу
1. **Пользовательские цвета сфер**: механизм выбора цвета сферы сохранён
   (левая полоса-идентификатор); дефолтная палитра новых сфер в app.js всё ещё
   разноцветная. Строгий Linear-режим = ограничить выбор ступенями
   индиго/серого. Решить: свобода цвета vs строгость (сейчас: свобода
   сохранена, чтобы не менять поведение).
2. **Светлая тема**: выведена из эксплуатации (скрыта, визуально инертна),
   код toggleTheme не удалён. Удалять ли совсем — решение владельца.
3. **Эмодзи-иконки сфер** (🏃📖🎯) — живут в данных пользователя; Linear-строже
   были бы monoline-иконки. Оставлены (это контент, не хром).

## Пилот «Вариант А — Тихая глубина» (экран «Сегодня»)
Спека Миры Коваль (студия Белькова) поверх Linear-канона выше — данные
«дышат» глубиной, а не украшением:
- **Тени включены токеном**: `--sh1/2/3` были `none` (объявлены, но нигде не
  использовались) → реальная шкала `0 1px 3px` / `0 2px 6px` / `0 4px 12px
  rgba(0,0,0,.4)` (светлая тема — та же шкала, ниже альфа: `rgba(28,27,23,…)`,
  тёмная тень на светлом фоне читается грязно).
- **`.state-hero`** (герой состояния + радар-компас на «Сегодня») получил
  `box-shadow:var(--sh1)` — карточка «парит» над лестницей поверхностей, не
  меняя hairline-границу и радиус.
- **Заголовок приветствия** (`.h-hl`, «Доброе утро») — `2rem/510` →
  `3rem/580`. Только домашний экран; `.sp-hl` (другой экран) не тронут —
  пилот scoped, не общий рефактор.
- Радар уже «дышит» (`#compass{animation:rdrBreathe 4.2s…}`) и уже стоит
  героем первого экрана (не под «показать больше») — оба пункта спеки Миры
  были фактом ДО этого пилота, правка не понадобилась.
- `prefers-reduced-motion` не затронут (изменения не про motion).

**Не входит в этот пилот** (сознательно, чтобы не раздувать фронт одним PR):
переразметка меню в 3 вкладки вместо 5, ритм сетки остальных экранов
(«Сферы», «Разум», «Итоги»), цветовая палитра варианта B «Тёплый дневник».
Once Иван подтвердит вариант A по факту пилота — это отдельные наряды.

**Проверка**: `npm run build` — dist/ собран; `node --check` на build.mjs/
tests/e2e.mjs/sw.js/app.js — чисто; JS не тронут вообще (правка только CSS +
`design/tokens.json` регенерирован тем же генератором). `npm test`
(playwright e2e) в этой среде не запускается — несовпадение версии Chromium
у пакета (нужен revision 1228, в контейнере есть только 1194) — известный
инфраструктурный шум этого окружения, не дефект правки; markup/id/классы не
менялись, так что риск для e2e минимален.
