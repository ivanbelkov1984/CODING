# Архитектор — дизайн «красиво И со смыслом»

> Принцип (по запросу владельца): за каждым красивым визуалом стоит **реальная
> функция и реальный расчёт из данных**, а не украшение. Мы берём у топ-приложений
> не картинку, а **механику**, и привязываем к нашим данным.

## Что стоит за визуалами топ-приложений (изучено)

| Приложение | Визуал | Реальная функция за ним |
|---|---|---|
| **Oura** | кольцо «readiness 78/100» | Композит из сна/ЧСС/HRV; ключевой механизм — **сравнение последних дней с личной 14-дневной базой**; contributors тапабельны (видно, что потянуло вниз). |
| **Daylio** | «год в пикселях» (сетка дней) | Запись в 2 тапа → тап на день = детали; **движок корреляций** «состояние выше в дни с X»; периоды с/без; средние по интервалу. |
| **Obsidian** | граф связей | Двусторонние ссылки; **хабы** (узлы с макс. входящими) показывают, где сгущается интерес; поиск кластеров и пробелов. |

## Наши визуалы → наши реальные функции

### 1. Герой «Состояние сегодня N/100» (механика Oura)
- **Расчёт:** композит из последнего чек-ина: сон `sl` (8ч≈макс), качество сна `sq`,
  спокойствие `10-st`, ясность `cl`, движение `mv` → 0–100.
- **База (как у Oura):** среднее за 3 дня vs среднее за 14 дней → дельта «↑/↓ за неделю».
- **Прозрачность:** тап по числу → разбор contributors (сон/спокойствие/ясность/движение),
  каждый со своим под-баллом и меткой выше/ниже твоей базы.
- **Честность:** <3 чек-инов за 14 дней → «мало данных», а не выдуманное число.
- **Функция:** `stateScore()` (расширяет существующий `deriveAxes`).

### 2. Тепловая карта «Настроение · 30/90 дней» (механика Daylio)
- **Расчёт:** один квадрат = день, цвет = композит состояния того дня.
- **Drill-down:** тап по дню → чек-ин этого дня.
- **Приверженность:** пропуски = серые клетки → питает стрик.
- **Функция:** `moodHeatmap(days)`; питает корреляции.

### 3. Корреляции «сон ↔ состояние» (killer-функция Daylio, наш дифференциатор)
- **Расчёт:** связь между сном и композитом состояния и т.п.
- **Честность:** метка уверенности по n (мало данных → «наблюдение», не «вывод»).
- **Функция:** `correlations()`.

### 4. Граф связей как герой (механика Obsidian) — УЖЕ ЕСТЬ
- `buildGraph()` по `[[ссылкам]]`, размер узла = степень (= хабы Obsidian),
  тап → инсайт, бэклинки в деталях. Выносим наверх.

## Навигация: 6 вкладок → 3
- **Сейчас** — состояние-герой + чек-ин + тепловая карта (сегодня и динамика).
- **Разум** — граф-карта (герой) + инсайты/книга/сны/паттерны (по фильтру, без дублей).
- **Итоги** — дайджест/ретро/AI-обзор.

Оси жизни рисуются **один раз** (в «Сейчас»), инсайты/паттерны живут в одном месте.
