# Пред-ЗКП UX-аудит — 2026-09-01

## Решение по границе работы

ЗКП не интегрируется в этой итерации. Цель прохода — довести уже существующий
«Архитектор жизни» до понятного пользовательского состояния без новой схемы,
новых writers и параллельной оболочки.

## Что фактически является приложением сейчас

- Experience 2.0 включена по умолчанию и является основным UX-path.
- Legacy-оболочка остаётся внутренним fallback через `arch_nav_v2=0`.
- Обе оболочки открывают те же DOM-формы, вызывают те же handlers и пишут в те
  же canonical collections. Отдельных `x2Save*` / `x2Write*` нет.
- Create, edit, correction, delete, import, sync, backup и Record Inspector не
  разделены между old/new UI.

## Пользовательская структура после прохода

| область | первый слой | второй слой |
|---|---|---|
| Сегодня | актуальная дата, подсказка, напоминание, «Жизнь сейчас» | стрики, история, графики и подробная динамика под «Подробнее о дне» |
| Дневник | Обзор · Записи · Сны · Повторы | Диалоги, Связи, Книга, Закономерности, Практики и смыслы, Мой путь в полном списке разделов |

| Здоровье | что требует внимания и план на сегодня | лекарства; симптомы; анализы/документы; привычки — четыре свёрнутые области |
| Астрология | Моя карта · Сейчас · Долгие периоды · Год и месяц · Совместимость | профессиональные расчёты под «Дополнительные расчёты» |

Глобальное меню содержит только семь пространств: Сегодня, Дневник,
Психология, Здоровье, Астрология, Источники, Настройки. Нижний островок:
Сегодня · Дневник · ＋ · Психология · Астрология. Меню открывается только
кнопкой справа в шапке.

## «Зачем?»

Отдельного пользовательского раздела «Зачем?» нет. Существующая коллекция
`whys` и `saveWhy()` сохранены как внутренний canonical contract, а UI является
пошаговым «Разбором ситуации»: один понятный вопрос на экран, прогресс, возврат
назад и один маленький следующий шаг. Он доступен в контексте Психологии и из
общего действия записи.

## Ранее обсуждавшиеся функции

### Женский цикл

В доступных документах Drive, коде default branch, GitHub issues/PR и
локальных remote refs не найден утверждённый контракт трекера менструального
цикла. Текущий Health data contract не содержит соответствующей canonical
сущности. Поэтому медицинская функция не имитируется UI-карточкой: сначала
нужно восстановить исходную спецификацию, правила приватности, состояния цикла
и границы медицинских выводов.

### ИПСИ

Найден отдельный репозиторий `ivanbelkov1984/supervisiya`, ветка
`ipsi-canon-temp`. Его материалы описывают учебно-исследовательскую среду,
CORE24, SimLab и супервизию, а не готовый self-help flow для пользователя
«Архитектора». Поэтому техническая аббревиатура «ИПСИ» не добавлена в первый
слой Психологии. Перенос отдельных проверенных приёмов возможен только после
продуктовой и safety-рецензии и с человеческими названиями задач.

## Неизменённые контракты

- schema и canonical semantics;
- route/hash compatibility;
- create/edit/delete/correction writers;
- sync, import, backup и Record Inspector;
- исходные идентификаторы психологических методов и provenance enums;
- все скрытые во втором слое функции остаются достижимыми.
