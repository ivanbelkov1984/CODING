# Архитектор — Baseline Findings: accessibility и UX-дефекты (Этап 0)

Снимок дефектов текущего MAIN, зафиксированных при обходе. **В этом PR они НЕ исправляются** — это отправная точка для последующих задач роадмапа. Живой отчёт пересобирается в CI (`evidence/REPORT.md`, `evidence/a11y-report.json`).

Методологическая оговорка: accessibility smoke — эвристика по отрисованному DOM, а не полный WCAG-аудит. Контраст оценивается по вычисленным цветам без учёта градиентов/картинок. Числа трактовать как «зоны внимания» и приоритеты, а не как строгий вердикт.

## 1. Accessibility smoke (24 прогона: ключевые экраны × тёмная/светлая)

| Класс | Уникальных дефектов | Что значит |
| --- | --- | --- |
| `icon-name` | 10 | иконка-кнопка/тоггл без доступного имени — VoiceOver прочитает «кнопка» |
| `tap-size` | 43 | тап-цель меньше 44×44 px |
| `focusable` | 26 | клик на `div/span` без `tabindex`/`role` — недостижим с клавиатуры |
| `affordance` | 4 | `onclick` на элементе без `cursor:pointer` |
| `contrast` | 62 | контраст текста ниже WCAG AA (4.5:1 / 3:1) |

### Приоритетные примеры

**Контраст (наиболее серьёзное):**
- `button.btn-p` (главный CTA) — **1.81:1** при норме 4.5:1 · встречается на онбординге, туре, создании зашифрованного backup. Белый текст на светло-голубой заливке — системная проблема основной кнопки.
- `button.emo.on` (выбранная эмоция в чек-ине) — **1.92:1**.
- `span.slv` (значения слайдеров момента) — **2.77:1**.
- `span.side-status` (статус синка в сайдбаре) — **3.11:1**.
- Множество мелких подписей 12–13px (`.f-lbl`, `.acct-sub`, `label`) — **3.49:1**.

**Клавиатурная недостижимость / тогглы без имени:**
- Тогглы веществ в чек-ине (`#tog-nic/caf/alc/sugar`) и согласия астрологии (`#aic-diary/health/habits`) — это `div` с `onclick`, без `role`/`tabindex` и без доступного имени → и с клавиатуры недостижимы, и screen reader их не назовёт.
- Строки-ряды `div.srow`, пилюли подменю `div.snpill`, карточки сфер `div.sph-card` — тапабельны, но не в tab-порядке.

**Тап-цели < 44px** (частые): кнопки-пилюли `.tp`/`.wp` в быстром вводе (38–49px по высоте), крестики оверлеев `.mdl-x` (32×32), кнопки чата `.chat-send` (36×36), чекбокс `#fb-ctx` (16×16).

## 2. Перегруженные экраны

- **Сегодня (Today)** — контент ~**2.1×** высоты вьюпорта, **9** тапаемых действий выше линии сгиба, при 7 top-level направлениях навигации. Экран совмещает приветствие, 5 быстрых действий, стрик, nudge, моменты, тренд и т.д. — «dashboard из нескольких продуктов» (подтверждает раздел 3 `01-CURRENT-UX-AUDIT.md`).
- **Астрология** — самый глубокий домен (≈5 МБ текстов, 11 под-экранов: натал, транзиты, прогрессии, возвращения, синастрия, Джйотиш, средние точки, точки, жребии, ректификация). Профессиональные техники конкурируют с базовыми жизненными функциями как равноправные top-level карточки.

## 3. Непоследовательные компоненты

- **Основной CTA (`btn-p`)** имеет недостаточный контраст текста везде, где используется — это один компонент, а не разовый экран; чинится централизованно в дизайн-системе.
- **Паттерн «тоггл»** (`.tog`) реализован как `div` с `onclick` — без роли, имени и фокуса; повторяется в чек-ине, согласии астрологии, настройках дневной карточки.
- **Тапаемые элементы без роли** (`.srow`, `.snpill`, `.fpill`, `.sph-card`, `.si-row`, `.ins-actions`) — единый архитектурный паттерн «div-как-кнопка», ломающий клавиатурную доступность по всему приложению.
- **Отображение поля `tone`**: тайл «Тонус» на экране Сферы (`app.js` ~5731) показывает `v.tone` без запасного значения, тогда как соседний рендер (~7739) использует `v.tone || '—'`. На неполных/легаси-данных первый вариант даст «undefined». (Найдено при построении фикстур; для реального чек-ина `tone` всегда задан, поэтому дефект проявляется только на частичных данных.)

- **JS-ошибок приложения при обходе: 0** (внешние сетевые ошибки к CDN/бэкенду/AI отфильтрованы как не относящиеся к коду).

Эти находки — вход для следующих этапов роадмапа, а не задачи текущего PR:
