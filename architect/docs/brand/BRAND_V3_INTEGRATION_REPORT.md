# Brand v3 — интеграция в приложение

Реализация `CLAUDE_BRAND_INTEGRATION_V3.md` и `BRAND_ASSET_PACKAGE_V3.md`.
База: MAIN `76d0b90`, ветка `claude/brand-integration-v3`, отдельный Draft PR.
Работа не пересекается с мостом внешних источников (PR #169).

## 1. Проверка исходников

Все 24 файла из `life_architect_brand_kit_v3_FINAL.zip` сверены по SHA-256 с
`BRAND_ASSET_V3_SHA256SUMS.txt` — совпадение полное. В репозиторий добавлены
19 PNG (`architect/brand/`); `00-source-mockup-reference.png` намеренно НЕ
добавлен: он только reference и не должен иметь шанса попасть в рантайм.
Совпадение SHA-256 повторно проверяется тестом при каждом прогоне CI.

## 3. Что заменено

Удалены старые `icon-192.png`, `icon-512.png`, `apple-touch-icon-180.png` —
на них больше нет ссылок (manifest, `<head>`, service worker, build). Второй
манифест и вторая cache-архитектура не создавались: используются
существующие `manifest.json`, `sw.js` SHELL и `build.mjs`.

Изменения по файлам:
- `manifest.json` — `name` → «Архитектор жизни» (`short_name` без изменений),
  4 иконки (192/512 any + 192/512 maskable) на новые пути; `start_url`,
  `scope`, `display`, `theme_color`, `background_color` не тронуты.
- `index.html` — favicon 32/64/192, apple-touch-icon 180; знак в шапке и
  сайдбаре; splash; полный lockup на первом запуске; блок «О приложении».
- `styles.css` — правила `.brand-mark`/`.brand-lockup` (`object-fit: contain`,
  пропорции, `max-width:100%`), размеры знака 36px (мобильный) / 40px
  (постоянный сайдбар), отключение градиентной плитки под растровым знаком,
  скрытие знака в шапке там, где виден постоянный сайдбар.
- `sw.js` — брендовые ассеты в существующем app-shell precache; иконка push.
- `build.mjs` — копирование только используемых в рантайме брендовых файлов,
  участие их хешей в версии сборки, очистка `dist/` перед полной сборкой
  (иначе заменённые файлы оставались бы в артефакте).

## 3b. Единый источник правды о сборке и идентичности

- Блок «О приложении» рендерит `rAbout()` из существующего `releaseInfo()`
  (Wave 5 release metadata contract): сборка, schema, SHA, время сборки.
  Захардкоженной «v5.0» в разметке больше нет — тест падает, если она
  вернётся.
- `<title>` и meta description ведут с «Архитектор жизни».
- `apple-mobile-web-app-title` осознанно остаётся «Архитектор» и равен
  `manifest.short_name`: iOS обрезает подпись значка примерно на 11–12
  знаках, и «Архитектор жизни» превратилось бы в «Архитектор ж…». Это
  зафиксировано тестом, а не оставлено на догадку.

## 4. Правила, соблюдённые буквально

- Никакого `object-fit: cover`; только `contain` + сохранение пропорций.
- Ни один контейнер не обрезает свечение, скруглённый квадрат, книгу и
  последние буквы слова «жизни» — проверено и тестом, и глазами на кадрах.
- Рядом с живым HTML-заголовком используется только знак: растровое
  название не дублируется. На первом запуске наоборот — lockup несёт
  название, поэтому текстовый заголовок убран.
- Доменные иконки разделов (Дневник, Здоровье, Астрология…) не заменены
  логотипом; знак не повторяется по карточкам — только шапка/сайдбар,
  splash, первый запуск и «О приложении».
- Нет CSS-фильтров/инверсии; глобальные токены дизайна не менялись.
- Все ассеты локальные, без CDN; сеть при брендинге = 0 запросов.
- Все кандидаты `srcset` — derivative'ы ОДНОГО иконочного мастера с
  одинаковой геометрией. `12-splash-brand-1024.png` (отдельная композиция с
  большим внутренним полем) кандидатом не является и в сборку не идёт:
  смешивать разные композиции как responsive-варианты нельзя.

## 5. Тесты и доказательства

`tests/brand-v3.spec.mjs` — 103 проверки (включена в `npm test`):

- SHA-256 всех утверждённых ассетов; отсутствие reference/мастера в сборке;
- манифест: имя, 192/512 any, 192/512 maskable, реальное существование
  файлов, maskable ≠ any;
- service worker: брендовый precache, отсутствие старых путей, один манифест;
- splash: фирменный знак, декоративная разметка, отсутствие задержки старта;
- шапка: размер 36–48px, `contain`, `alt=""`/`aria-hidden`, отсутствие
  столкновений, высота шапки не выросла (71px — как на MAIN);
- первый запуск: lockup с доступным именем «Архитектор жизни», без
  текстового дубля, пропорции и полная видимость внутри карточки;
- «О приложении»: знак + живое название + версия, без двойного озвучивания;
- навигация: доменные иконки целы, знак не размножен;
- адаптив 320/375/390/430/landscape/768/834/desktop: нет горизонтального
  переполнения, знак виден ровно один раз, ничего не обрезано;
- светлая тема: без фильтров и подложки, тот же размер;
- maskable под круглой и squircle-масками;
- офлайн-доступность изображений, отсутствие внешних запросов, битых URL
  и JS-ошибок.

Скриншоты: `evidence/brand/` (шапка и первый запуск для всех размеров,
splash, светлая/тёмная «О приложении», maskable под масками).

**Визуальная приёмка глазами** (не только зелёный CI): просмотрены кадры
320/390/834, splash, первый запуск, «О приложении» в обеих темах и maskable
под масками. По итогам просмотра исправлены два реальных дефекта, которые
тесты сами по себе не поймали бы: кадры снимались поверх splash/overlay, и
на планшете знак дублировался (шапка + постоянный сайдбар).
