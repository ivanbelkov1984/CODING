## Что работает (по разделам навигации)

| Раздел | Функции |
|---|---|
| **Сегодня** | check-in (RULER), инсайты, сны, моменты (valence×activation), «Зачем?», серии/стрики, умные подсказки, «в этот день», недельная сводка, напоминание о приёме по плану, opt-in карточка «Транзит дня» |
| **Сферы** | пользовательские сферы (привычка/счётчик/цель), логи, статистика |
| **Разум** | инсайты, граф связей, книга (главы), паттерны, сны, духовное, эволюция, чаты |
| **Итоги** | living map, обзоры за 30/365 дней, корреляции |
| **Здоровье** | план и факт приёма (раздельные классы), симптомы, измерения, отчёт для врача (факты без интерпретации), privacyClass=sensitive |
| **Астрология** | отдельный раздел: натальная карта (SVG-колесо на весь экран, 6 систем домов включая Кох, полный портрет: интро → «Кто вы по карте» → Asc/MC → синтез стихий/качеств/полушарий/стеллиумов, табы), транзиты (календарь, bi-wheel, карточки), прогрессии/дирекции/профекции, соляр/лунар, астероиды и точки, мидпоинты/гармоники, джйотиш (South + North Indian, даши, панчанга), арабские точки и звёзды, синастрия, **уточнение времени рождения (ректификация — инструмент сужения диапазона по жизненным событиям)**, база из 2076 профессиональных текстов с тапом на любом элементе, 2 режима ИИ (быстрый Haiku / глубокий Sonnet с согласием и минимизацией) |
| **Настройки** | профили, темы, E2EE-синк, зашифрованная переносимая резервная копия, экспорт/импорт, ключи AI-провайдеров, бюджет AI, уведомления |

## Инфраструктура качества
- **389 e2e-тестов** (Playwright, реальный браузер), golden-сверки с JPL Horizons / альманахом / Меёсом; CI на каждый PR + evidence-workflow.
- Evidence Kernel: паспорт записи (kType/verif/life), append-only коррекции.
- Изоляция доменов: астрология ни во что не подмешивается; здоровье — организатор, не медицина (без диагнозов/доз-логики).
- Все AI-вызовы через одну точку с бюджетом и леджером (без контента).
