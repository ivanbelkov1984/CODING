# Wave 9 — Mind–Body Context Layer

> issue [#164](https://github.com/ivanbelkov1984/CODING/issues/164) (addendum-
> комментариев нет; действуют ограничения addendum `5230889736` Волны 8).
> База — свежий `MAIN` `5ce7f8a76133dcc6c4d67284f967d71107575651` (merge Волны 8,
> PR #166). SHA перепроверен на remote перед созданием ветки.

Derived-слой **временных ассоциаций** между психологическим контекстом и
телесными симптомами. Показывает повторяющиеся совпадения по дням — **не
диагноз, не причинность, не «психосоматическое объяснение»**.

## 1. Архитектура: полностью derived

- **Ни одной новой коллекции, ни одного нового EVENT_SOURCE, ни второго
  ledger'а.** `mindBodyAssociations(db)` — чистая функция, пересчитывается при
  каждом рендере из canonical записей; правка/удаление/tombstone источника
  меняет результат детерминированно.
- `SCHEMA_VERSION` **не поднимается** (остаётся 8): записи не меняются.
  Единственное персистентное состояние — скаляр `mindBodySettings`
  (`hiddenAssociations[]`, `mutedThemes[]`), LWW-документ, зарегистрирован в
  `SCALAR_REGISTRY`, sync/backup генерично, подхватывается shallow-merge без
  миграции.

## 2. Источники истины (source IDs всегда раскрыты)

- психология: `psyObservations` (timestamp, EMA-цепочка, contextTag),
  `psyInterventionEpisodes` (targetProblem/Mechanism/summary), `moments`
  (emo/note);
- здоровье: `symptoms` (точное нормализованное имя = ключ; **разные симптомы
  никогда не сливаются по похожему тексту**);
- `measures`/`labObservations` в v1 не участвуют в ассоциациях (см. §8).

## 3. Темы: независимая transdiagnostic taxonomy

`MB_THEMES`: `uncertainty / control / autonomy / connection / safety / loss` —
детерминированные словари ключевых корней по пользовательскому тексту.
Происхождение — общая транстеоретическая психология; **GNM/Hamer/Recall
Healing не использованы даже как источник taxonomy**. Никаких
TAS-20/alexithymia-скорингов из текста, никакого ACE-множителя, никакого
polyvagal state machine (закреплено мутациями).

## 4. Движок v1 — детерминированный, локальный, offline

Гранулярность — **день** (симптомы и события в MAIN датируются днём; более
узкие окна были бы ложной точностью):

- окна: `same_day`, `psych_before_body` (+1 день), `body_before_psych`
  (−1 день); **чувствительность показана по всем окнам** — один выбор окна не
  выдаётся за истину;
- эпизод = день с психологическим событием темы; co-occurrence = симптом в
  окне; **отсутствие записи ≠ отсутствие симптома** (ограничение хранится в
  каждой ассоциации);
- `lagDirection`: concurrent / psych_before_body / body_before_psych / mixed
  (при равенстве окон — mixed);
- `evidenceState` — enum, не число: `insufficient` → `candidate` (ровно 2
  совпадения) → `repeated_association` (≥3 совпадений, ≥4 эпизодов, доля ≥½)
  → `context_dependent` (повторяется в одном contextTag-контексте и явно
  отсутствует в другом);
- **никакого произвольного `confidence 0..1`** (мутация сторожит);
- confounders детерминированы и сохраняются всегда: другие симптомы в те же
  дни, приём препаратов, «сон/нагрузка/внешние события не контролировались»;
- `safeReflectionText` — только язык совпадения («причинность не
  установлена»); возврат причинных формулировок убивается мутацией;
- `associationId` детерминирован (`mb:<тема>|<симптом>`), `engineVersion` =
  `mind-body-engine-v1`;
- **медицинские red flags** (грудная боль, кровь, обморок, онемение, одышка,
  температура…) исключаются из психологических ассоциаций полностью и
  показываются как медицинский маршрут («обратись к врачу») — fail-closed.

## 5. UX: контекстные карточки, не отдельный экран

- «Тело и контекст» в Psychology Workspace и «Совпадения с контекстом» в
  Здоровье — один рендер `mbRenderCards()`;
- карточка показывается только при `repeated_association`/`context_dependent`
  (минимум повторяемости до показа); `candidate` — счётчиком «накапливается»;
- у каждой карточки «Почему система это заметила?» → contributing source IDs,
  окна, движок, ограничения;
- «Скрыть» (конкретная ассоциация) и «Не отслеживать тему» — числовые индексы
  в inline-обработчиках, обратимо («Показать скрытое»).

## 6. AI

Не участвует: слой полностью детерминирован, 0 сетевых вызовов, AI-леджер
пуст (тест). Позднейшее «объяснение человеческим языком» потребует отдельного
consent и не сможет менять evidenceState.

## 8. Известные ограничения

1. `measures`/`labObservations` не участвуют в ассоциациях v1 — числовым
   рядам нужна направленная логика порогов, иначе ложная точность.
2. Темы — фиксированный словарь v1; пользовательские словари не реализованы.
3. Гранулярность — день; внутридневные лаги (±6h) невозможны без timestamp у
   симптомов.
4. В аналитике («Закономерности») отдельная поверхность не добавлена — слой
   доступен из Психологии и Здоровья.
5. Полнотекстовое сопоставление тем — по ключевым корням; это фильтр
   контекста, а не NLP-классификатор с валидированной точностью.

## 9. Rollback

Слой аддитивен и derived: удаление Wave-9 блока `app.js`, скаляра
`mindBodySettings` и двух вызовов `mbRenderCards()` возвращает поведение
`MAIN 5ce7f8a`. Данные пользователя не мигрировались.
