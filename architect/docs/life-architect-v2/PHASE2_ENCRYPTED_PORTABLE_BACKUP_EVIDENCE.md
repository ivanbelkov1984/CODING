# Phase 2 P2-A implementation evidence — encrypted portable backup

Status: `PHASE_2_P2_A_IMPLEMENTED_DRAFT`

## Runtime cryptography

- Adapter: `backup-adapter.js`.
- KDF: PBKDF2 with SHA-256, 210000 iterations, fresh 16-byte salt per backup.
- Authenticated encryption: AES-GCM 256-bit key, fresh 12-byte IV per backup, 128-bit tag.
- Envelope format: `ARCHITECT_ENCRYPTED_PORTABLE_BACKUP`, version `1`.
- Authenticated data binds format, version and backup mode.
- Manifest digest is verified after decrypt and before restore planning.

## Inclusion inventory

Included for the selected profile only:

- `insights`, `dreams`, `patterns`, `evolution`, `spiritual`, `checkins`;
- `spheres`, `sphereLogs`, `bots`, `chapters`, `digests`, `chats`, `cravings`, `oq`;
- scalar stores `vit`, `env`, collection tombstones `_del`, scalar timestamp `__ts`;
- optional `_meta` fields because records are cloned without stripping additive metadata;
- safe portable configuration fields;
- complete-mode media manifest entries and IndexedDB media objects.

Excluded:

- `spaceKey`, `apiUrl`, `lastSync`, configuration `_ts`;
- passphrase/recovery/provider/backend/API key shaped configuration fields;
- feedback diagnostics/outbox/sent IDs, caches, service-worker internals and unrelated profiles.

Machine-readable inventory is generated by `tests/evidence/encrypted_backup_regression.mjs` as `tests/artifacts/encrypted-backup-test-report.json`.

## Restore safety

Restore parses and validates the plaintext envelope header before password entry, authenticates/decrypts before mutation, plans a summary, defaults to a new profile, rejects non-empty targets unless replacement is explicit, creates a pre-restore snapshot key, writes staged DB/config/media, and rolls the DB slot back on write/parse failure.

## Evidence limitations

Automated focused backup tests and build pass locally. Full Playwright E2E and mobile evidence require browser binaries; this environment could not download Playwright browsers because the CDN returned HTTP 403 on `npx playwright install chromium webkit`. No physical iPhone/iPad testing is claimed in this implementation draft.
