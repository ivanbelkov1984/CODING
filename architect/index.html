AI (Claude)
API-ключ Anthropic
Модель
Ключ хранится только на этом устройстве. Запросы идут напрямую в Anthropic — минуя наш сервер. Ключ получить: console.anthropic.com → API Keys. С ключом AI работает автономно и незаметно (сам дописывает обзор недели, собирает живую карту), а вручную открывается только диалог «Копни глубже».
Как синхронизировать: укажи URL — дальше всё автоматически: любое изменение само уходит на сервер (оффлайн — сохранится при возврате сети). Чтобы открыть данные на втором устройстве, впиши тот же URL, Ключ пространства и ту же парольную фразу, затем «Загрузить с сервера».

Каждый профиль — отдельное пространство с собственными данными, ключом и парольной фразой. Удобно разделять, например, «Личное» и «Работу».

Создастся чистый профиль. Данные текущего профиля останутся на месте — переключиться можно в любой момент.
Резервные копии
Приложение само делает снимок данных каждый день (хранятся 7 дней). Можно откатиться на любой из них или скачать копию на устройство.
