Как защищены твои данные
🔒 Память — end-to-end зашифрована
Если задана парольная фраза, всё шифруется в твоём браузере (AES-GCM). На сервер синка уходят только шифроблоки. Ни сервер, ни разработчик, ни GitHub не видят твою память в открытом виде.
🤖 Честно про ИИ-разбор
Психоконтур, диалог, сонник, «Разобрать бережно» отправляют выбранный тобой текст напрямую твоему ИИ-провайдеру по твоему ключу — чтобы ИИ мог его прочитать и разобрать. Это не проходит через наш сервер, но провайдер этот фрагмент видит. Шифрование хранилища сюда не распространяется.
🔑 Забыл фразу?
Настоящее end-to-end не имеет «сброса пароля». Создай ключ восстановления — это единственный способ войти, если забудешь фразу. Без него и без фразы данные не восстановить никому, включая нас.
Без парольной фразы синхронизация идёт в открытом виде. Задай фразу, чтобы включить end-to-end.
Ты сейчас не один
Похоже, тебе очень тяжело. Это важнее любого приёма из приложения — и с этим не нужно оставаться наедине.
Если есть угроза прямо сейчас — позвони в скорую или экстренную службу твоего региона. «Архитектор» — не терапевт и не заменяет живого человека.

Расходы AI
Ключ хранится только на этом устройстве. Запросы идут напрямую в Anthropic — минуя наш сервер. Ключ получить: console.anthropic.com → API Keys. С ключом AI работает автономно и незаметно (сам дописывает обзор недели, собирает живую карту), а вручную открывается только диалог «Копни глубже».
Как синхронизировать: укажи URL — дальше всё автоматически: любое изменение само уходит на сервер (оффлайн — сохранится при возврате сети). Чтобы открыть данные на втором устройстве, впиши тот же URL, Ключ пространства и ту же парольную фразу, затем «Загрузить с сервера».

Импорт из ChatGPT
Как получить архив: в ChatGPT открой Settings → Data controls → Export data. На почту придёт ссылка на zip (готовится до 7 дней, живёт 24 часа — скачай сразу). Выбери здесь этот zip или файл conversations.json из него. Архив разбирается на этом устройстве и никуда не отправляется.
Профили
Каждый профиль — отдельное пространство с собственными данными, ключом и парольной фразой. Удобно разделять, например, «Личное» и «Работу».

Резервные копии
Приложение само делает снимок данных каждый день (хранятся 7 дней). Можно откатиться на любой из них или скачать копию на устройство.
Журнал синхронизации

По умолчанию будет создан новый профиль. Существующие профили не изменяются; новый профиль активируется только после полной проверки.
