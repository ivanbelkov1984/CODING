Шаг 1 из 7 Можно пропустить
Опиши один конкретный момент своими словами: событие, чувство или повторяющееся действие.
Не ищи далёкую причину. Подумай, какую задачу это решает прямо сейчас.
Даже неудобная привычка может временно давать облегчение, контроль, внимание или паузу.
Назови потребность простыми словами: безопасность, близость, отдых, ясность, уважение, свобода.
Что становится хуже, если продолжать так же: состояние, отношения, время, деньги или здоровье?
Выбери безопасный и реалистичный способ, который не требует идеального состояния.
Шаг должен быть конкретным и посильным — таким, который можно сделать сегодня.

Как защищены твои данные
🔒 Память — end-to-end зашифрована
Если задана парольная фраза, всё шифруется в твоём браузере (AES-GCM). На сервер синка уходят только шифроблоки. Ни сервер, ни разработчик, ни GitHub не видят твою память в открытом виде.
🤖 Честно про ИИ-разбор
Психоконтур, диалог, сонник, «Разобрать бережно» отправляют выбранный тобой текст напрямую твоему ИИ-провайдеру по твоему ключу — чтобы ИИ мог его прочитать и разобрать. Это не проходит через наш сервер, но провайдер этот фрагмент видит. Шифрование хранилища сюда не распространяется.
🔑 Забыл фразу?
Настоящее end-to-end не имеет «сброса пароля». Создай ключ восстановления — это единственный способ войти, если забудешь фразу. Без него и без фразы данные не восстановить никому, включая нас.
Без парольной фразы синхронизация идёт в открытом виде. Задай фразу, чтобы включить end-to-end.
Ты сейчас не один
Похоже, тебе очень тяжело. Это важнее любого приёма из приложения — и с этим не нужно оставаться наедине.
Если есть угроза прямо сейчас — позвони в скорую или экстренную службу твоего региона. «Архитектор» — не терапевт и не заменяет живого человека.

Google Drive · идентификатор приложения (Client ID)
Это публичный идентификатор приложения из Google Cloud Console, а не пароль и не токен. Он виден в любом браузерном приложении Google и хранится в обычных настройках. Ключ доступа к твоему Drive здесь не хранится никогда: он живёт только в памяти открытой вкладки и исчезает при перезапуске.
Google Drive · Browser API key для Picker
Отдельная от Client ID вещь: без неё окно выбора файлов Google (Picker) не открывается. Как получить: тот же проект Google Cloud → включить Google Picker API → создать ключ типа «API key».
Ключ обязательно ограничить: в разделе ограничений приложения выбрать HTTP referrer и указать адрес этого приложения, а в ограничениях API оставить только те Google API, которые ему нужны. Без ограничений ключ сможет использовать чужой сайт и расходовать твою квоту — поэтому это и не пароль, и не безобидная публичная строка.
Токен доступа сюда не вводится никогда — он появляется только при входе в Google и живёт лишь в памяти вкладки.

Источники и история импорта
Хранилище и диагностика
Постоянное хранилище снижает риск автоматической очистки браузером. Полной гарантии не даёт: операционная система всё равно вправе освободить место. Регулярная резервная копия остаётся основной защитой.
Отчёт содержит только версии, счётчики и коды ошибок. Записи дневника, здоровье, психологию, отношения, данные рождения и ключи он не включает.
Журнал синхронизации
Последние события: сеть, синхронизация, ошибки. Помогает понять, что происходит с данными.
