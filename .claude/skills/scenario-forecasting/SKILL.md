# Scenario Forecasting

Use `04-SCENARIO_FORECASTING_SPEC.md`.

Reject arbitrary formulas combining astrology, psychological friction and a Kurzweil exponent. First define event outcome, horizon, eligibility, observation process and baseline. MVP may output readiness/momentum/scenario signals, not calibrated event probabilities.

A probability model requires representative data, temporal holdout, external/evaluation data, calibration plot/slope/intercept, Brier/log loss, uncertainty and governance. Astrology features remain isolated experimental covariates and enter production only if they add stable out-of-sample value beyond behavioral/context baselines. Intervention effects require causal experiments such as MRT, not observational correlation.
