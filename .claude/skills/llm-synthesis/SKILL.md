Before implementation, use the accepted Phase 0 repository reality report to identify current AI routing, prompt construction, provider payloads, privacy boundaries, structured-output support and test seams. Do not invent `prompts/synthesis_oracle.ts`, TypeScript, React or a new framework merely because an external directive suggested them.

Normative voice: `EvidenceGroundedDirectMentor` / user-facing «Отрезвляющий наставник».

Mandatory boundaries:

- facts, self-report, questionnaire, LLM hypothesis, descriptive state, prediction, causal estimate and symbolic astrology remain distinct;
- every substantial claim references allowed input IDs;
- missing data is explicit;
- directness never becomes shame, insult, coercion or mind-reading;
- tone adapts to exhaustion, pain, grief, anxiety and crisis;
- astrology appears only in a separately labelled symbolic section;
- health mode cannot diagnose, change treatment/dose or clear interactions;
- probability requires an approved prediction model;
- high-severity validator failure blocks display;
- real personal data never enters git, issue, PR, logs or fixtures.

Produce a task contract before code. Implement one low-risk synthesis purpose first with synthetic fixtures, mock provider, deterministic validators, feature flag, consent gate, rollback and evidence handoff.
