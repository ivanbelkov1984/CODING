# Context Handoff

Update `.claude/handoffs/CURRENT.md` with:

- objective and current phase;
- exact branch/commit;
- files read/changed;
- decisions and their authority;
- commands/tests and results;
- blockers/risks;
- next atomic task;
- files the next agent must read;
- facts that must not be inferred from old context.

Do not paste full logs or research. Link paths and retain only decisions/evidence.
