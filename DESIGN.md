# Design System: Архитектор жизни

Записаны подтверждённые владельцем токены режимов подачи. Режим — явный
переключатель на стороне пользователя (см. `PRODUCT.md` → Capabilities and
Constraints): **Calm** — база, **Bold** — энергичный акцент.

Цифры и названия ниже внесены буквально по решению владельца. Не менять и не
«улучшать» без явного решения Ивана.

> Не путать с `architect/DESIGN.md` — там разбор механик топ-приложений
> (Oura / Daylio / Obsidian) и обоснование «за каждым визуалом реальный расчёт».
> Этот файл — визуальная система; тот — обоснование функций.

## Calm — День

Референс: **Oura**.

### Токены

```css
--bg: #f7f1e8;
--bg-alt: #efe6db;
--text: #4a4741;
--muted: #a8a5a0;
--ink-950: #1c1b1a;
--slate: #27455c;
--accent: #2a72de;
--accent-hover: #2056a6;
```

### Шрифты

- Гротеск (**AkkuratLL / Söhne / General Sans**) — для основного текста.
- **Serif italic (Editorial New)** — только для одного акцентного слова в заголовке.

### Компоненты

- **Кнопки:** `border-radius: 9999px`, высота `48px`.
- **Карточки:** радиус `8–12px`, hairline границы `#d3d1ce`.

### Отступы

Модуль отступов — `8px`.

## Calm — Ночь

Референс: **Things 3**-эстетика.

### Токены

```css
--bg: #0C0C0C;
--surface: #141416;
--accent: #B9A8F0;
```

### Шрифты

- **Inter Tight** — заголовки.
- **Inter** — текст.

### Иконки

Тонкая линия, без заливки и теней.

### Правило акцента

Акцент только на активной вкладке и завершённых действиях.
